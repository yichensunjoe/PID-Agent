# P055-PID-Agent — 需求与范围

## 用户意图

让工程人员与 AI Agent 在同一份结构化 P&ID 上协作：人工可在浏览器编辑，Agent 可读取连接语义并提交受校验、可撤销的事务，最终可导出工程交换和报告产物。

## 核心目标

1. 统一设备、端口、连接节点、管线、图层和属性的文档模型。
2. 所有人工、REST、Python、MCP 与 LLM 修改都进入同一个事务服务。
3. 使用 revision 乐观并发和原子事务防止 Agent 覆盖人工修改。
4. 提供可继续编辑的项目 JSON、图像/PDF/DXF 和工程报表导出。
5. 单机默认安全，共享部署时显式认证、CORS 与 Provider 网络边界。

## 范围

- 浏览器 SVG P&ID 编辑器与标准单位图例。
- FastAPI REST、Python Client、MCP stdio 和 OpenAI-compatible 规划器。
- SQLite 持久化、migration、备份/恢复、撤销/重做。
- 工程拓扑摘要、设备/管线/仪表报表和确定性质量检查。
- JSON、SVG、PNG、PDF、DXF 导入导出。

## 非目标

- 不替代通用 CAD、机械三维、BIM 或有限元软件。
- 模型不能直接写数据库或绕过服务层执行任意代码。
- 不承诺 Alpha 格式永久不变；迁移必须经过版本和恢复检查。
- 默认不提供公网多租户托管、企业 SSO 或审批工作流。

## 约束与假设

- Python 3.11+、Node.js 20+；PNG/PDF 导出需要 Cairo/Pango。
- 连接语义正确与图面美观是两个独立验收维度。
- 共享部署必须启用认证、CORS 白名单、请求上限与 Provider 网络控制。
- 本地数据库和备份是敏感运行数据，权限至少 `0600`，且不得进入 Git。

## 验收标准

- 后端测试、Ruff、前端单测与构建通过。
- Playwright 验证创建、编辑、连接、撤销/重做、导入/导出和共享部署路径。
- 离线 quality harness 验证图例、端口、拓扑和 Agent 事务。
- 并发旧 revision 被拒且事务无部分写入。
- 备份可在隔离副本恢复并通过 SQLite 完整性、外键与实例身份检查。
